# Growth asset design brief

Audience: freelance SEOs, agency practitioners and website owners reviewing a concrete problem.
High-value action: use a resource successfully, then request professional help when the evidence needs deeper investigation.
Page jobs: inspect supplied HTML; download editable workflow documents; assess a documented self-audit.
Evidence: actual markup input, source revision da343a2 and public responses observed 5 September 2026. No private analytics or invented client results.
Constraints: retain Astro, Tailwind and the existing content layout. No server-side URL fetching or new paid infrastructure.

Visual anchors: audit check IDs and evidence-to-action records. The tool gives each finding an observation and a next step; the resource page groups downloads by work task. Use a clear source-input panel and plain report rows instead of an invented overall score.
Hierarchy: scope -> input or download -> observed evidence -> interpretation -> next action.
Tokens: retain dark ink surfaces and cyan action colour. Use readable muted text and visible focus outlines. Error states use text and an alert role, not colour alone. The printable PDF keeps a white page and dark text.
Mobile: labels above inputs, wrapping button groups, full-width source field and readable results. Reduced motion disables decorative animation and smooth scrolling.

Reference principles: Google's documentation separates observations from indexing conclusions. The HTML template element provides an inert parsing surface. Competitor resource pages observed in the growth review make samples directly downloadable; AuditWeb adds an implementation tracker and explicit verification states.

Safe direction: retain the existing editorial content layout.
Stronger direction selected for the checker: make the supplied source and resulting evidence the main interaction. No fabricated health score or decorative progress animation.
